# Kit · academic

**System:** `academic` (see `../../references/design.md` §1).
**Audience:** thesis committee, advisor, reviewers, conference audience.
**Reader task:** judge the problem, method, evidence, and contribution — and
decide whether the work is credible and worth continuing.

## Narrative

```
context → gap → question/hypothesis → method → evidence → interpretation →
limitations → contribution → references (+ backup)
```

The first minute must make the problem and the claim clear. The body must let
a skeptical reader verify the claim without asking. A section divider is
optional and only useful when the deck runs past ~15 pages; a progress marker
is better than a divider on short decks.

## Required pages

| Page | Job |
|---|---|
| Title | Title, authors, affiliation, venue/date; one visual anchor. |
| Gap / background | What is known, what is missing, why it matters. |
| Research question | The exact question or hypothesis; scope and definitions. |
| Method | Data/sample, instrument, procedure, analysis; enough to reproduce. |
| Results — figure | The main evidence figure, complete and legible. |
| Results — table | The comparison or statistics table, three-line style. |
| Discussion / limitations | Interpretation, alternative explanations, threats to validity. |
| Conclusion / contribution | Answer the question; state the contribution and next step. |
| References | Cited works in one style, readable size. |

Optional: related work (only if the gap needs positioning), data availability,
appendix/backup (extra figures, robustness, derivations). Optional pages are
content-driven — do not add an agenda or dividers by reflex.

## Density and type

- Body 17–19 px, captions/sources 9–11 px, page titles 30–36 px, cover 48–64 px.
- Line height 1.25–1.45. Two families maximum; serif or neutral sans, one
  restrained accent.
- Regions are filled: a figure region holds a figure, not a figure plus 40%
  whitespace. Breathing room goes between regions, not inside them.
- One result per page. If a page has two conclusions, split it.

## Evidence rules

- Original figures and tables first. Re-plot only with real extracted data and
  mark "redrawn from [source]".
- Keep axes, legends, units, error bars, significance marks, and subpanel
  labels. Never crop a data figure to make it fit.
- Every figure/table: number + caption (what and under which condition) +
  source (authors, year, figure/table number).
- Method diagrams and experimental photos are evidence — never generate them.
- No stock imagery. No generated imagery by default.
- A claim never exceeds its evidence; limitations are visible, not buried.

## Do

- Make the title a claim or a precise question, not a topic label.
- Use the three-line table convention; align numbers on the decimal.
- State the sample, the comparison baseline, and the effect size.
- Put the interpretation next to the evidence, not three pages later.
- Keep section numbering and figure numbering consistent.

## Don't

- Don't use cards, gradients, soft shadows, colored headers, or decorative
  underlines.
- Don't recolor scientific figures to match the palette when color carries
  meaning.
- Don't enlarge an institutional emblem as decoration or watermark.
- Don't center body text; don't set body text below 15 px.
- Don't use a business blue-and-white skin for a life-sciences talk.
- Don't add a "thank you" page with no content; close with the answer.

## Anti-homogenization

- Page order follows the argument, not this file's table. Merge or reorder when
  the content demands it.
- Use at least four different page recipes in a deck of ten or more pages.
- No two consecutive pages share the same composition. The results-figure
  recipe offers left/right variants — alternate them.
- `fragments/` are single-page geometry references. Never assemble them into a
  fixed deck, never copy the kit as a whole.
- Vary the evidence rhythm: figure page → table page → statement page →
  diagram page. Do not run three chart pages in a row.

## Page map example (not a template)

```text
1 Title
2 Gap / why now
3 Research question
4 Method (design diagram)
5 Data and measures

8 Robustness / alternative explanation
9 Discussion + limitations
10 Conclusion / contribution
11 References
12 Backup (extra figures)
```
