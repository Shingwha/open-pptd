# Page recipe · results-table

**Purpose:** give the reader the numbers behind the claim, in a form they can
verify and compare.

**Reader task:** find the comparison, the effect, and the uncertainty without
hunting.

## Slots

1. Title: the comparison as a claim ("Model B outperforms A on every held-out
   set; the gap widens with noise").
2. Table: 3–6 columns, 4–8 rows; three-line style.
3. Highlight: bold or accent one row/column that carries the argument; leave
   the rest neutral.
4. Reading: one or two sentences on what the numbers mean; or a callout for the
   key value.
5. Notes: units, significance convention, n, and the model/metric definitions.
6. Source line.

## Variants

**A. Full-width table + reading strip** — table occupies 80–90% width; a short
reading sits below or beside the last row. The standard for a defense.

**B. Table + interpretation panel** — table 65%, right panel 30% with 2–3
findings. Use when the table needs explanation.

**C. Split comparison** — two small tables side by side for two conditions,
with a shared legend. Only when the comparison is the point; otherwise one
table is clearer.

## Selection

A by default. B when the table has more than five columns. C only for a
controlled A/B comparison with identical rows.

## Type and density

Body cells 13–15 px; header 13–14 px bold; notes 10–11 px. Numbers right
aligned, text left aligned, first column bold. Row height must fit the text;
if not, cut rows rather than shrink below 12 px.

## Table discipline

- Three-line table: top rule, header rule, bottom rule. No vertical lines, no
  zebra striping, no card cells.
- One decimal convention per column; state units in the header (`Mean (SD)`,
  `%`, `ms`).
- Significance: use `*`, `**`, `***` with a note, or exact p-values; never both.
- Keep the table's reading order identical to the figure's.
- Full table on this page; do not split a table across two pages.

## Evidence / caption

`Table 1. <what is compared>; <condition>; n = <n>.` Source below. If adapted,
say "adapted from" and keep the original numbering in the source.

## Do / Don't

Do: align decimals; bold the winning row; put the reading next to the table.
Don't: paste a spreadsheet with 12 columns; use color as the only encoding;
omit the units; use a card grid instead of a table.
