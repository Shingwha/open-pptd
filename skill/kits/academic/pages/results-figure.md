# Page recipe · results-figure

**Purpose:** present the main evidence as a single, complete, legible figure
and state what it shows.

**Reader task:** see the effect, judge its size and uncertainty, and know the
condition it came from.

## Slots

1. Title: the finding in words with the effect ("Treatment reduced Y by 38%,
   p < 0.01").
2. Figure: 55–75% of the content area, complete.
3. Reading: 2–4 short lines next to the figure — what to look at, the effect
   size, the comparison, the caveat.
4. Figure number + caption: what is shown, condition, n.
5. Source line: authors, year, figure/panel number.
6. Optional annotation: one arrow/callout on the figure area pointing at the
   inflection or the key contrast. Keep it outside the plot's data region.

## Variants

**A. Figure right, reading left** — the default for a landscape figure.

**B. Figure left, reading right** — alternate with A across result pages.

**C. Full-width figure + strip** — the figure spans 80–100% width, with a
one-line claim above and a narrow reading/caption strip below. Use only when
the figure is dense and needs the width.

## Selection

Choose by figure aspect ratio and the number of reading points. Never shrink a
dense multi-panel figure into a column; use C and put the reading in the strip.
Alternate A/B when two result pages run in sequence.

## Type and density

Title 28–34 px; reading 16–18 px; caption/source 10–11 px. The figure can be
dense; the surrounding text cannot. Do not overlay text on the plot area.

## Evidence / caption

- Use the original figure. `fit: contain`. Never crop axes, legend, or panel
  labels.
- Caption: `Figure 2. <what is plotted> under <condition>; n = <n>.`
- Source: `Source: <authors> (<year>), <journal>, Fig. <n>.`
- If re-plotted from extracted data: `Redrawn from <source>; values verified
  against Table <n>.`
- Error bars and significance marks must be explained in the caption.

## Do / Don't

Do: annotate one point; state the effect size in the title; keep the same
figure size across comparable results.
Don't: recolor the scientific encoding to match the deck; add a decorative
frame; use a screenshot of a table as a figure; crop a panel to fit.
