# Page recipe · method

**Purpose:** let a skeptical reader judge whether the design can answer the
question. This is a reasoning page, not a protocol dump.

**Reader task:** understand the sample, procedure, measures, and analysis well
enough to spot threats to validity.

## Slots

1. Title: the design choice and why ("Within-subject design isolates X from
   between-person variance").
2. Design diagram or sequence: participants/materials → conditions → measures.
3. Sample: n, selection, setting, period.
4. Measures: construct → operationalization → instrument (small table if >3).
5. Analysis: model/test and the assumption it depends on.
6. One limitation preview only if it changes the interpretation (otherwise
   save for the discussion page).

## Variants

**A. Horizontal flow** — 4–6 numbered stages across the page, with the sample
and measures below each stage. Native shapes/lines only.

**B. Split design/measures** — left 60%: design diagram; right 40%: sample and
measures as a compact definition list. Good for experiments.

**C. Three-line table** — when the method is a comparison of instruments or
datasets, a narrow table (condition, n, instrument, outcome) is cleaner than a
diagram.

## Selection

A for procedures with a clear order; B for experiments; C for multi-dataset or
multi-instrument work. Do not use a diagram for a method that is essentially a
table.

## Type and density

Medium-high. Title 28–34 px; stage labels 13–15 px; body 16–18 px. The diagram
must fit the planned region — no 30% empty box. Keep one reading direction
(left→right or top→bottom), never both.

## Evidence / caption

If the diagram is adapted from a prior protocol, cite it. Equipment photos are
evidence: caption with model/setting and source. No generated lab imagery.

## Do / Don't

Do: state n and the unit of analysis; name the test and the software version if
relevant; show where bias could enter.
Don't: paste an appendix-sized protocol; use decorative lab icons; omit the
sample size; draw a flow with inconsistent arrow weights.
