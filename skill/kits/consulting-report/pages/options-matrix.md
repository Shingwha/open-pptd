# Page recipe · options matrix

**Purpose:** compare the real choices on explicit criteria and show why one
wins.

**Reader task:** see the trade-offs and accept the recommended option.

## Slots

1. Title: the choice ("Partnership wins on speed and risk; entry wins only on
   long-run margin").
2. Matrix: options as columns, criteria as rows; each cell a score or a short
   verdict; a weight column if the scoring is quantitative.
3. Recommendation mark: the chosen option marked once (label + accent).
4. Reading: 2–3 lines on the decisive criterion and the main trade-off.
5. Source/assumption line.

## Variants

**A. Criteria × options table** — 3 options, 4–6 criteria. The default.

**B. Scorecard** — weighted scores with a total row; use only when the weights
are agreed and defensible.

**C. Two-axis map** — options plotted on cost vs speed, with a quadrant
reading. Use for a conceptual choice, not a financial decision.

## Selection

A for a standard appraisal; B for a quantitative business case; C when the
audience needs the shape of the trade-off, not the arithmetic. Do not use a
matrix with one option pre-filled as the winner and no criteria.

## Type and density

Medium-high. Matrix cells 11–13 px; criteria 12–14 px; reading 14–16 px. Keep
the matrix readable: 3–4 options and no more than 6 criteria. Put long
definitions in the appendix.

## Evidence / caption

State how scores were derived (expert judgement, model, benchmark) and the
weight of each criterion. If a score is qualitative, say so. Source line for
any external benchmark. The matrix is an argument, not a data table.

## Do / Don't

Do: keep criteria independent; mark the recommendation once; show the losing
option fairly.
Don't: use 5 options; weight criteria after seeing the scores; use color as the
only encoding; hide a disqualifying criterion.
