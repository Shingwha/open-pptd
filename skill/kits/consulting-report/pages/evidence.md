# Page recipe · evidence

**Purpose:** provide the exhibit that decides the case. This is the page the
recommendation rests on.

**Reader task:** see the number, trust the source, and accept the implication.

## Slots

1. Title: the exhibit's finding, not its topic ("Segment A grows 3× faster but
   needs a different channel").
2. Exhibit: one chart or table, 55–75% of the content area.
3. Reading: 2–3 lines on what the exhibit shows and what it implies for the
   decision.
4. Source, period, unit, and definition.
5. Counter-mark (optional): the one data point that weakens the reading.

## Variants

**A. Chart + reading column** — the default for a trend or comparison.

**B. Table + interpretation panel** — for a multi-criteria comparison or a
financial model summary.

**C. Two-panel exhibit** — one chart and one small table that answer the same
question from two angles. Use only when both are necessary.

## Selection

A for a single quantitative claim; B when precision and definitions matter; C
when the case needs both a trend and a level. Do not use two unrelated charts.

## Type and density

High density is allowed in the exhibit, not in the reading. Chart labels
10–12 px; reading 14–16 px; source 9–11 px. De-default the chart: no vertical
grid, no default palette, labels only at key points.

## Evidence / caption

`Exhibit 3. <finding>; <metric>, <period>, <unit>.` Source below. State the
definition and the comparison basis. If the exhibit is an estimate, show the
range and the method.

## Do / Don't

Do: annotate the one point that matters; show the baseline; keep the exhibit
title as a finding.
Don't: use a 3-D chart; cut the y-axis silently; use an unlabeled index; put
three exhibits on one page.
