# Page recipe · visual system

**Purpose:** turn the concept into rules someone else can apply.

**Reader task:** see the palette, type, grid, image treatment, and motif as one
system — and know what not to do.

## Slots

1. Title: the system's principle ("One blue field, one cropped numeral, no
   decoration").
2. Palette: 4–6 swatches with names and usage share; primary/accent plus
   neutral.
3. Type: display and body specimen with sizes and weights; one line of real
   copy.
4. Grid/composition: 2–3 proportions or a margin rule, drawn.
5. Image treatment: one crop/duotone/halftone rule, shown on an example.
6. Motif: the repeated element with its allowed states.

## Variants

**A. Specimen board** — palette left, type specimen right, grid and image
treatment below. The default.

**B. System in use** — show a real application (poster, packaging, social) with
numbered callouts to the rules. Better for a non-design audience.

**C. Rules list** — 6–8 one-line rules with small visual examples. Use as the
appendix or for a brand book page.

## Selection

A for a design-literate jury; B for a client who needs to see it working; C for
a system handoff. Do not show more than two type families or six colors.

## Type and density

Medium-high. Swatches 40–80 px tall; type specimen 40–72 px; rule labels 9–11
px. Keep the page aligned to the same grid as the rest of the deck.

## Evidence / caption

Palette values are design decisions, not evidence. If the colors come from the
brand's existing assets, note the source. Show usage share (primary ≤ 10%,
ground ≥ 60%) as a rule, not a measured claim.

## Do / Don't

Do: show the system on a real format; name the rules; include one "don't"
example.
Don't: show 12 swatches; use unreadable type specimens; claim accessibility
without contrast values.
