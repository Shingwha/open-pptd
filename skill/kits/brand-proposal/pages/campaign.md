# Page recipe · campaign / applications

**Purpose:** prove the idea travels across touchpoints without losing its
identity.

**Reader task:** see the campaign in real formats and believe it can be
produced.

## Slots

1. Title: the campaign line or the application conclusion.
2. 2–3 applications: poster, packaging, social, retail, film still, event.
   Each has a format label and a one-line role.
3. System markers: the same motif/type/color visible in each application.
4. Production note: one line on what must stay fixed and what can flex.

## Variants

**A. Three-up applications** — three frames in a row, one motif repeated. The
default.

**B. Hero + detail** — one large application and two detail crops. Use when the
main format is the pitch.

**C. Channel matrix** — applications mapped to channel and audience moment.
Use for a media-led proposal.

## Selection

A for a visual campaign; B for packaging/retail; C for a multi-channel launch.
Do not show more than three formats — the page is proof, not a portfolio.

## Type and density

Medium. Application labels 9–11 px; campaign line 24–40 px. Keep the frames
aligned; a collage of different sizes reads as indecision.

## Evidence / caption

Label mockups as mockups. If the application uses a real product/photo, credit
it. Generated imagery is expression; record prompts and do not imply a
photoshoot happened.

## Do / Don't

Do: show the system surviving different formats; keep one campaign line.
Don't: use unrelated images; show five formats with no hierarchy; fake a
billboard in a real city with a real brand.
