# Page recipe · practice

**Purpose:** give the learner a task they can start now, with a check that makes
success visible without waiting for the instructor.

**Reader task:** know exactly what to produce, how long it should take, and how
to tell whether it is right.

## Slots

1. Kicker: "PRACTICE" plus the skill being trained.
2. Title: the task as an imperative ("Rewrite the query so it uses the index").
3. Task: one to three sentences, with the input and the required output.
4. Constraints: time, tools allowed, format, and what not to change.
5. Check: "You are right when…" — observable criteria, one to three bullets.
6. Hint: one nudge that does not give the answer away; optionally an answer key
   in small type at the bottom or on the next page.
7. Optional pair roles for a two-person exercise.

## Variants

**A. Task + check + hint** — one task, criteria on the right, hint in a muted
footer. The default.

**B. Three tiers** — warm-up / core / stretch, each with its own check. Use for
mixed-ability groups; the core tier is mandatory.

**C. Pair exercise** — two roles with separate instructions, a shared check, and
a two-minute debrief question. Use for communication and review skills.

## Selection

A for individual exercises; B when the group's level is unknown; C when the
skill is conversational or review-based. Never put two unrelated tasks on one
page — split or choose one.

## Type and density

Title 30–36 px; task 20–24 px; constraints and check 16–18 px; hint/answer
14–16 px. The task must be readable from the back row; the check must be visible
while working, not only in the answer key.

## Evidence / caption

Practice data comes from the same real dataset or case as the example, so the
learner transfers rather than re-learns. State the source and the sample. An
answer key is allowed; a fabricated "typical student answer" is not.

## Do / Don't

Do: state the output format; give a check the learner can run alone; keep the
hint separate from the answer.
Don't: ask for "discussion" without a product; hide the criteria until the end;
make the task depend on material not on the previous pages; use a task that is
only solvable by guessing.
