# 颜色令牌与色系

> 按需读取：选题、配色调色时参考本文。风格类型（排版方案）见 `styles.md`，格式语法见 `pptd-format.md`。
> 风格×配色搭配速查见 `styles.md` 各风格的「推荐配色」；预置主题组合（含字体）见 `styles.md` 第 0.6 节。

## 1. 颜色令牌

| 令牌 | 含义 | mckinsey 主题值 |
|---|---|---|
| `$primary` | 主色（页眉/表头/柱状） | `#051C2C` 墨蓝 |
| `$accent` | 强调色（装饰线/标签） | `#00A0DC` 亮蓝 |
| `$bg` | 背景 | `#FFFFFF` |
| `$text` | 正文 | `#1B2A3A` |
| `$muted` | 次要文字 | `#5A6B7C` |
| `$line` | 分隔线/网格线 | `#E2E8EE` |
| `$success` / `$warning` / `$danger` | 语义色 | 绿/棕/红 |
| `$series` | 图表系列色板（8 色） | 主色系深浅阶梯+辅助色 |

文字样式令牌：`$title`(32 bold) / `$subtitle`(16 muted) / `$body`(16) / `$caption`(12 muted) / `$quote`(16 italic)。

派生色令牌（预览跟随主题切换，导出输出解析后的具体色值 = 预览所见）：
- `$primary-deep`：primary 混 28% 黑（封面/结尾深底）
- `$primary-soft`：primary 混 94% 白（KPI 卡底、结论条底、目录卡底）
- `$primary-tint`：primary 混 88% 白（浅色强调底）
- 令牌透明度：`$primary20` = primary @ 20/255 alpha（章节大数字），两位 hex 任意

颜色写法：`#RRGGBB`、`#RRGGBBAA`、`$令牌`、`$派生令牌`、`$令牌NN`。
**元素显式省略的样式自动从主题取——换主题全页联动；封面/结尾/卡片底色一律用令牌，禁止写死主题 hex。**
（例外：风格特征背景——深色/纸底等属于风格而非色系，写死 hex，见 `styles.md`。）

表格/图表样式自动从 primary 派生（表头=primary、边框=primary 浅色调、斑马纹=primary 极浅、图表系列=色板），切主题即全页联动。
现代高级排版：封面/结尾用纯深色块（不用渐变）；章节页浅纯色底；信息页白底 + 大留白 + 单一强调色点缀。

风格特征背景（深色/纸底）写死在页面里不受色系影响；其余颜色一律令牌化，换色系即全页联动。
字体不属于色系（属于风格层）：`deck.pptd` 的 `fonts` 字段声明，推荐字体、直链与写法见 `fonts.md`。
