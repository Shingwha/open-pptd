# 风格类型（排版方案）

> 按需读取：定风格、设计页面布局时参考本文。配色见 `themes.md`，格式语法见 `pptd-format.md`。
>
> **风格 = 排版方案，配色 = 色系，两者正交**：先按场景选风格类型，再从 `themes.md` 挑色系搭配。
> 风格特征（深底/纸底等背景色）作为风格的一部分写死在页面里；主题令牌（`$primary` 等）只负责语义色——换色系全页联动，换风格换整套排版。
>
> **字体 = 风格层**：在 `deck.pptd` 的 `fonts` 字段声明（见 `pptd-format.md`），不写 = 微软雅黑。

## 0. 所有风格共享的骨架（content 页）

- 右上角页码（primary 13px bold）
- 底部页脚 caption（左：项目名；右：CONFIDENTIAL）
- 无渐变无阴影（组件限制）；字号单位为 960×540 画布 px

## 0.5 字体建议（速查；完整清单/直链/YAML 写法见 `fonts.md`）

| 字体 | 英文名 | 气质 | 推荐风格 |
|---|---|---|---|
| 微软雅黑 | `Microsoft YaHei` | 现代无衬线（默认） | mckinsey / dark-tech / minimal / morandi |
| 楷体 | `KaiTi` | 手写温润、文气 | zhongshi 新中式 |
| 宋体 | `SimSun` | 衬线印刷、报纸感 | retro 复古 / 学术 |
| 黑体 | `SimHei` | 粗犷庄重、标题感 | official 政务标题 |
| 仿宋 | `FangSong` | 公文感 | official 政务正文（元素级覆盖） |
| 幼圆 | `YouYuan` | 圆润可爱 | playful 活力教育 |

> 网络字体（高级气质，OFL 可嵌入：思源宋体/思源黑体/EB Garamond/霞鹜文楷/站酷小薇）推荐清单与验证过的直链、资源表 YAML 写法见 **`fonts.md`**；`themes/01-商务经典/` 是网络字体资源表的完整样板。

## 0.6 预置主题组合（三维：风格 × 色系 × 字体）

颜色、风格类型、字体**三个维度正交，任意自由组合**；下表是每个风格的**主推组合**（主题 = 锁定好的特定组合），换色系/换字体随时可拆开重配。

> 注意：**主题是引导，不是模板**：预置主题只是「这个场景的起点配置」（色系+风格+字体+示例页型），**生成具体 deck 时必须按内容做配套优化**——选匹配的图标/形状（见 `components.md`）、按内容定布局（学术用公式+图表、发布会用大图大字、政务用表格+庄重对称）、按气质调字体（系统字体池见 0.5 节）。**禁止原样照搬主题页**：示例页的标题/数据/卡片结构都要换成你的内容，`themes/` 里的页面是「写法的样例」，不是「可复用的成品」。

| 主题名 | 风格 | 色系 | 字体（标题 / 正文 / 表格 / 图表） | 场景 |
|---|---|---|---|---|
| 麦肯锡咨询 | mckinsey | `mckinsey` | 思源宋体 / 思源黑体 / 思源黑体 / 思源黑体 | 战略汇报（默认） |
| 深色科技 | dark-tech | `cyan` | 雅黑 / 雅黑 / 雅黑 / 雅黑 | 发布会/技术分享 |
| 新中式 | zhongshi | `vermilion` | 楷体 / 楷体 / 楷体 / 楷体 | 文化/文旅/庆典（全字体统一） |
| 政务红金 | official | `vermilion` | 黑体 / 仿宋 / 仿宋 / 黑体 | 党建/政府/大会（标题图表黑体、正文表格仿宋） |
| 复古报纸 | retro | `brown` | 宋体 / 宋体 / 宋体 / 宋体 | 展览/文创/怀旧（全字体统一） |
| 活力课堂 | playful | `yellow` | 幼圆 / 幼圆 / 幼圆 / 幼圆 | 培训/课件/校园（全字体统一） |
| 极简黑白 | minimal | `black` | 雅黑 / 雅黑 / 雅黑 / 雅黑 | 设计/学术/高端 |
| 莫兰迪生活 | morandi | `morandi` | 雅黑 / 雅黑 / 雅黑 / 雅黑 | 生活方式/家居 |
| **学术论文** | **academic** | `blue` | 雅黑 / 雅黑 / 雅黑 / 雅黑 | **论文汇报/学术答辩/组会** |
| **青松手册** | **handbook** | `pine` | 雅黑 / 雅黑 / 雅黑 / 雅黑 | **制度宣贯/项目手册/审计合规** |

**组件字体配置要点（克制）**：数据可读性优先，现代无衬线组合（商务/科技/极简/莫兰迪）全组件雅黑无需声明；风格化字体组合按气质配 `title`/`body`，**需要全字体统一**（表格图表也跟随）时声明 `table`/`chart` 组件，如新中式；政务红金特殊——标题图表黑体、正文表格仿宋（中西文分工用 `{latin, ea}` 对象或组件槽均可）。

> 注意：**组件字体全页生效**：用 `style: "$title"` 等令牌的元素用对应组件字体；无 style 引用的普通元素自动继承 `$body` 正文组件字体——声明 `fonts.body` 后全页文字统一生效，无需逐个元素写。

组合声明示例（新中式 · 全字体统一）：
```yaml
theme: vermilion
fonts:
  title: KaiTi
  body: KaiTi
  table: KaiTi   # 表格也用楷体
  chart: KaiTi   # 图表也用楷体
```

## 1. mckinsey — 麦肯锡咨询（默认）

- **定义**：咨询风格，信息密度高、结论先行、墨蓝 + 亮蓝、衬线标题
- **适用**：战略汇报、经营分析、投融资路演、年度复盘
- **推荐配色**：`mckinsey`（墨蓝 `#051C2C` + 亮蓝 `#00A0DC`）/ `blue` / `gray` / `green`
- **推荐字体**：思源宋体标题 + 思源黑体正文 + EB Garamond 西文（网络字体，见 `fonts.md` 第 5 节组合配方；无网络时回退雅黑）
- **页型配方**：
  - cover：`$primary-deep` 深底 + 顶部 4px accent 亮蓝细条 + 11px accent 保密角标（STRICTLY PRIVATE…）+ 44px 白衬线大标题 + 标题上方 56×4 accent 短装饰线 + 17px 半透明副标题 + 右下同心圆环（ellipse border `#FFFFFF22`/`#FFFFFF14`）+ 右上 `#FFFFFF0D` 年份水印
  - agenda（toc）：白底 + 左侧 32px 衬线大编号 01-04 + 16px 标题 + 12px 描述 + `$line` 分隔线；右侧 `$primary-soft` 说明卡（内含三色块 PRIMARY/ACCENT/TEAL）
  - chapter：白底 + 6×84 accent 竖条 + PART 0X 标签 + 36px 衬线标题 + 右下 170px `$primary10` 超大衬线数字 + 底部 4 圆点进度
  - content：白底 + 左上 11px accent 章节标签（01 · TYPOGRAPHY）+ 22px 衬线标题 + 右上页码；页脚分隔线 `$line` + 左下项目名 + 右下 CONFIDENTIAL
  - final：`$primary-deep` 深底 + 居中 40px 白衬线“感谢聆听” + accent 短线 + 图标+文字联系行 + 右下同心圆环 + 底部保密条
- **信息密集页公式**：4 张 KPI 卡（roundRect `$primary-soft` 底 + 20px primary 大数字 + 11px muted 标签）→ 图表并排（柱状双系列 / 面积+折线 / 环形图）→ 5×4 表格 → **结论条**（`$primary-soft` 底 + 4px accent 竖条 + 一句话结论）
- **数据写法**：一律“xx 亿 / +22% / -8pct”式；KPI 卡 4 个一组；图表数据 5-8 行；表格 4-6 行
- **参考**：`themes/01-商务经典/`（全页型样板，7 页含字体/图表/视觉展示）

## 2. dark-tech — 深色科技

- **定义**：深底浅字、霓虹点缀、大数字大留白，发布会气质
- **适用**：产品发布、技术分享、研发规划、黑客松/极客路演
- **推荐配色**：`cyan` / `purple` / `orange`
- **推荐字体**：微软雅黑（默认，无需声明）
- **页型配方**：
  - cover：`#0B1220` 深底 + 52px 白大标题 + accent 细线 + 右下超大数字水印（accent 低透明）+ 细网格线装饰（`#FFFFFF14` 细线）
  - chapter：`#0B1220` 深底 + 150px accent 大数字（低透明）+ 白标题 + accent 短竖条
  - toc：深底 + 白字卡片（`#FFFFFF0F` 底 + `#FFFFFF1F` 边框）+ accent 编号
  - content：深底 + 白标题 + accent 装饰线；卡片 `#FFFFFF0F` 底 + `#FFFFFF1F` 边框；图表/表格系列选亮色主题（cyan 等，深底上对比才够）

- **要点**：深底 hex 写死（风格特征）；文字白 `#FFFFFF` / 次级 `#FFFFFFB3`；accent 用亮霓虹色；圆角卡 adjustments 14000-20000；忌大面积白底

- **定义**：米纸底、墨字、朱砂点缀、细线框、大留白，东方文气

- **推荐配色**：`vermilion`（朱砂）/ `olive` / `brown`
- **推荐字体**：楷体 `KaiTi`
- **页型配方**：
  - cover：`#F7F3EA` 米纸底 + 44px 墨字大标题 + 朱砂印章式方块（56×56 rect）+ 上下双细线 + 大留白
  - chapter：米纸底 + 超大数字（`$primary` 低透明）+ 朱砂细横线 + 墨字标题
  - toc：米纸底 + 细线分隔列表（不用卡片底）+ 朱砂编号
  - content：米纸底或白底 + 墨字标题 + 朱砂小标签；卡片用细边框（1px `$line`）不用大色块

## 4. minimal — 极简

- **定义**：白底、超大标题、零装饰、留白 50%
- **适用**：设计提案、学术答辩、高端品牌、艺术展
- **推荐配色**：`black` / `gray` / `blue`
- **推荐字体**：微软雅黑（默认，无需声明）
- **页型配方**：
  - cover：白底 + 左下 48-56px 黑超大标题 + 12px muted 小字；无装饰线无水印
  - chapter：白底 + 200px 浅灰大数字（`$line` 色）+ 24px 小标题
  - toc：纯文字列表（数字 + 标题 + 描述），无卡片
  - content：白底 + 24-28px 标题；无顶部色条无装饰条；KPI 用数字直接排或 `#F5F5F5` 极浅卡；表格关斑马纹（zebra 用白）；图表关网格
  - final：白底 + 大号黑字 + 极小 muted 说明
- **要点**：只用灰阶（`$text` / `$muted` / `$line`）；不用 accent；少用形状；留白宁大勿小

## 9. academic — 学术论文

- **定义**：白底、深蓝主色、统一页眉页脚、编号体系（Eq./Fig./Table/章节号），信息密集但留白克制
- **适用**：论文汇报、学术答辩、组会、开题/结题、技术评审
- **推荐配色**：`blue` / `gray` / `black`
- **推荐字体**：微软雅黑（默认，无需声明）
- **页型配方**：
  - cover：白底 + 顶部 4px 主色条 + 会议/期刊标签（accent 小字）+ 38px 深蓝标题 + 英文副题 + 细分隔线 + 作者/单位 + 日期
  - chapter：左侧 220px 深蓝竖条（`$primary-deep`）+ 96px 白色大章节号 + CHAPTER 标签 + 右侧章节名
  - toc：深蓝编号块（34px 方卡白字）+ 标题 + 右对齐页码
  - content：统一页眉（章节名 + 页码 + 浅灰分隔线）+ 小节标题（accent 竖条 + 主色加粗，如 `3.1 模型定义`）+ 公式/图表/表格带编号（(1)、图 1、表 1）
  - final：分层结论（编号条目）+ 未来工作 + 参考文献（10px muted 单倍行距）
- **要点**：颜色克制（主色 + 灰阶，accent 仅用于小节竖条）；页眉页脚六页统一；公式元素用 `color: "$primary"` 可联动主题色；信息密度高但保留 48px 页边距；参考文献字号 10-11px

## 10. handbook — 规范手册

- **定义**：白底文档感、条款式正文、编号徽章、细线分隔，像一本装订精良的机构手册（制度汇编 / 产品手册 / SOP 气质）
- **适用**：制度宣贯、项目管理手册、审计合规、产品说明、内部规范
- **推荐配色**：`pine`（青松，默认）/ `gray` / `blue`
- **推荐字体**：微软雅黑（默认，无需声明）
- **页型配方**：
  - cover：白底（不用深色块）+ 顶部 4px 装订线 + 左上文件编号（小方块徽章 + 编号文字）+ 右上密级标签 + 40px 深绿大标题 + 沙金短装饰线 + 右下文档属性栏（细边框：版本 / 生效日期 / 编制部门）
  - chapter：白底 + 左侧「印章式」大编号方块（120px rect 深绿底白字，直角不用圆角）+ 章节名 + 沙金线 + 条款式要点（行首条款号 `1.1` 主色加粗 + 标题 + 描述，行间 1px 细线）
  - toc：书刊目录——编号小方块（28px 深绿白字）+ 章节名 + 引导点线（dash 细线）+ 右对齐页码，条目间 1px 细线
  - content：页眉文档头（`文件编号 · 第 0X 章`）+ 顶部 4px 细线；小节标题 = 编号小方块（24px 深绿白字，如 `2.1`）+ 标题 + 沙金短线；条款正文行首条款号 + 细线分隔，**不用卡片底色**；流程用 chevron 步骤条（adjustments 18000-22000，全 primary 统一色 + 白字）；清单行首 `check` 图标（16-18px）；底部结论条 = 白底细边框 + 左 3px 主色竖条（区别于 mckinsey 的色块结论条）
  - final：附则页——生效条款（行首小方块 + 细线分隔）+ 修订记录小表格 + 右下落款（编制部门 + 日期，公文感）
- **要点**：全页白底（文档感，无深底封面/章节）；装饰语言只有三种——**编号方块、细线、chevron 步骤条**，其余形状不用；icon 每页 ≤ 3 且只在清单/核对场景（check / list-check / shield-check），流程条内不放图标；图/表一律带编号题注（图 1 / 表 1），数据页底部附「数据口径」说明小字；无圆角大卡、无水印数字、无星形强调
