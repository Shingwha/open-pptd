# Style Brief — 白露 · 二十四节气文化海报

- Goal and audience: 让人在节气当天停下来看一眼，记住"露从今夜白"的意象；受众是关注传统文化的社交媒体读者与手机壁纸收藏者。
- Output scenario and canvas: 手机竖屏优先（壁纸/故事页），取 9:16 竖版 [540, 960]；直接按该比例构图。
- Core message in one sentence: 暑气尽，夜露白——秋天从今天早晨开始。
- Chosen visual concept/metaphor: ink-wash 留白——纸是雾，字是骨：一枚隶书"白露"竖立如碑，诗句以竖排细字相伴，一枚红印压角。
- Primary visual focus: 右侧竖排巨字「白/露」+ 朱红印章。
- Poster-level visual move (why this is not an ordinary content page): 全页只用一组竖排关系组织信息（巨字—诗—印皆竖），阅读顺序自右向左，整页读作一页竖排书影而非节气营销卡。
- Visual DNA: 暖纸白底大面积留白；唯一装饰是一枚淡月圆与朱印；笔画粗细对比来自字体本身，不画线描山水。
- Primary visual medium and asset candidates compared: 候选一为水墨山水插画——需位图素材且易流俗，落选；候选二为露珠摄影特写——同上，落选；候选三为纯排印竖排（选中）——节气的气质在文字与留白里，"白露"二字本身即最好的图。
- Reading order and composition: 右起「白」「露」竖排巨字 → 左侧竖排诗句《诗经·秦风》→ 印章压字尾 → 中部横排节气小注 → 底部三候一行 → 交节日期与页脚。
- Color scheme and each color's role: bg 暖纸白（雾气）；primary 黛青（小注与点线）；accent 印章红（一枚印与三候标记，全页唯二红点）；text 墨青（诗文巨字）；muted 苇灰（注释）。
- Chinese and English fonts, size hierarchy, and usage: 阿里妈妈刀隶体 Alimama DaoLiTi（巨字 155 / 日期 30 / 印文 24）+ 霞鹜文楷 LXGW WenKai（诗句竖排 28 / 引文 28 / 小注 13-18）；两族封顶。
- Image selection, cropping, and treatment: 无位图，全矢量可编辑；淡月以极淡圆示意，不描边。
- Graphics/chart/connector language: 仅两条发丝横线分区；无图形装饰。
- Information density, whitespace, and alignment: 上半区（竖排）只占一半信息量，下半区横排小注，两处大留白；边距 48px，诗句区右起左行。
- Tropes to avoid: 山水剪影+金句的"节气营销模板"、大面积红色国潮底、把三候做成图标卡片；防止退化成日签图——巨字必须够大（占页宽 1/3）才有碑感。
- 候选方向落选原因备查：插画向因素材与流俗风险落选；摄影向因素材约束落选。最易退化为"普通日签卡片"——检查时盯住「白/露」竖排巨字与印章是否构成第一眼记忆点。
