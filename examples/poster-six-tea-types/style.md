# Style Brief — 六大茶类 · 高密度信息图
- Goal / audience: 一页看懂六大茶类的差别；受众是茶爱好者、咖啡/茶饮从业者与信息图爱好者。
- Output scenario and canvas: 社媒竖版 / 打印信息图，2:3 竖版 [720, 1080]，高信息密度。
- Core message: 六大茶类的分水岭是一条「发酵轴」——从 0% 的绿茶到 100% 的黑茶。
- Visual concept: 以一条彩色发酵渐变轴贯穿全篇，下方用一张六行规格表承载「发酵度 / 代表茶 / 咖啡因 / 水温」，底部用雷达图对比风味，配图标化的冲泡指南。
- Primary visual focus: 发酵渐变轴 + 六行规格表。
- Poster-level move: 整页只有一条主轴与一张主表，其余信息（雷达、冲泡、注释）都围绕它们排布，密而不乱。
- Visual DNA: 宣纸米底 + 深茶绿主色 + 琥珀强调；茶汤色（绿/白/黄/琥珀/红/黑）只出现在色块与发酵轴；细线分区，无卡片墙、无阴影滥用。
- Charts: ①发酵渐变轴（6 色 stop）；②每行嵌入咖啡因横向迷你条；③雷达图对比绿茶与红茶的五维风味。
- Fonts: 标题/茶名 霞鹜文楷 LXGW WenKai（优雅楷体）；数据/正文 MiSans（清晰数字），两族封顶。
- Reading order: 眉标 → 标题 → 发酵轴 → 规格表 → 风味雷达 + 冲泡指南 → 注释。
- 数据说明: 咖啡因、水温为每杯约值（150ml），因品种、投茶量、冲泡方式而异，已在页脚标注。
- Avoid: 圆角卡片墙、彩虹配色、把六类茶做成六张一样的卡；发酵轴不要退化成装饰色带。
