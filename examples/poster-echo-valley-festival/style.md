# Style Brief — 山谷回声音乐节演出海报

- Goal and audience: 让乐迷 3 秒内记住「山谷回声」这场露宿音乐节的时间地点，并顺手记下一组艺人名；次要受众是转发海报的豆瓣/小红书用户。
- Output scenario and canvas: 手机竖屏浏览 + 打印易拉宝两用，取 2:3 竖版 [720, 1080]；直接按该比例构图，非 16:9 裁切。
- Core message in one sentence: 十月中旬，去山谷草坪听两天回声。
- Chosen visual concept/metaphor: 「暗场信号」——黑是空间不是底色；舞台声场化作同心日轮几何，一条细信号线把日期、阵容、票务三个事实节点串在一张声呐图上。
- Primary visual focus: 全幅演出现场照（人群剪影+舞台光束）+ 右上同心圆环（声场/日轮）+ 穿过圆环的巨型节名。
- Poster-level visual move (why this is not an ordinary content page): 标题字直接叠压进圆环几何，事实信息沿信号线节点分布，整页读作一张"声呐捕获图"而非信息卡片页。
- Visual DNA: 深蓝黑场域（现场照经分段渐变遮罩压暗）；几何语言为细圆环/弧线/节点圆点/虚线轨道；文字压在照片与几何之上；信息块不做边框卡片，靠字号阶梯与留白分区。
- Primary visual medium and asset candidates compared: 候选一为纯矢量声场几何——结构成立但缺现场温度，缩略图偏"图形海报"，落选；候选二为纯文字排版——缺记忆点，落选；候选三为真实演出照全幅背景 + 声场几何与巨字叠加（选中）——人群剪影自带"暗场"，舞台光束的品红/青与霓虹色板同族，照片即"暗场中的唯一亮源"，且为 Pexels 免费授权（media/SOURCE.md）。
- Reading order and composition: 顶部眉标 → 左上巨字节名（压圆环）→ 英文副标 → 日期大数字 → 信号线引入阵容区（两列阶梯字号）→ 早鸟票色带 → 页脚细字。
- Color scheme and each color's role: bg 深蓝黑（空间）；primary 薄荷霓虹（主字/圆环/信号线）；accent 荧光粉（副节点/强调）；accent3 琥珀（小卫星点缀）；正文近白、次要灰绿；色只服务节点与数字，不做满页霓虹。
- Chinese and English fonts, size hierarchy, and usage: 得意黑 Smiley Sans（展示：节名 96 / 日期 56 / 阵容 36-28 / CTA 19）+ MiSans（正文 15 / 注释 12 / 英文字距加宽）；两族封顶。
- Image selection, cropping, and treatment: 现场照全幅 cover 裁切（保留中景举手剪影与亮舞台），上覆 angle 90 线性渐变遮罩——上下压暗保眉标/标题/页脚对比度，中段透出光束与圆环相融；图源与许可见 media/SOURCE.md。
- Graphics/chart/connector language: 一条 smooth 细信号线（1.5px 薄荷）贯穿中景；节点为 8-12px 实心圆点，落在各信息块起点。
- Information density, whitespace, and alignment: 三段式（字/声场/阵容）留出两处大呼吸区；左右统一 48px 边距，阵容区两列 48/384 对齐。
- Tropes to avoid: 满页霓虹描边、赛博仪表盘、黑底小灰字长文、发光面板堆叠；以及把阵容做成等宽圆角卡片墙。
- 候选方向落选原因备查：纯矢量向因缺现场温度落选；纯排版向因缩略图无记忆点落选。最易退化为「黑色促销单页」或「照片糊脸音乐会模板」——检查时盯住照片是否被遮罩压到只剩"暗场中的亮源"、信号线与圆环是否仍在组织信息。
