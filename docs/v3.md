# open-pptd 桌面化整体重构方案（定稿 v9）

## 一、核心决策（已确认）
1. **统一资源目录** `~/.open-pptd/`（字体/cache/drafts/recents/settings/examples），桌面版与 CLI 共享；浏览器存储（Cache API/IDB/localStorage）在本地形态退役；线上 Pages 保持 Cache API + 句柄模式（同一抽象两套实现）
2. **字体不自带**：内置字体库管理面板统一下载（27 种全表 + ✓/✗ + 单个/全部 + 进度 + 删除），落点 `~/.open-pptd/fonts/`（CLI/桌面版共享），线上 Cache API；skill `assets/fonts/`（155MB）退役，registry.json 保留
3. **桌面版路径模式**：原生对话框/argv/拖放 → 真实路径 → 挂载内嵌 server（/api/project/mount，仅 127.0.0.1）；句柄模式保留给线上
4. **自动更新**：electron-updater + GitHub Releases（差分、可配镜像、不触碰用户数据目录）
5. **CLI 统一 `openpptd` + 三渠道同源**：skill zip 自包含 CLI（解压即用零 npm 依赖）；npm 包 openpptd 为可选增强；桌面版附带 CLI 给普通人
6. **历史遗留清理**（见 §十）

## 二、CLI 统一与三渠道
- bin `{"openpptd": "bin/openpptd.js"}`，子命令 `serve / export / export-project / render / gallery / fonts` 收敛其下；保留 open-pptd 别名
- skill zip 自包含（SKILL.md + references/ + bin/ + lib/ + editor/ + registry.json + package.json + index.html，~1-2MB 不含字体）；npm 包（零依赖纯 Node，版本=主 package.json，npm publish 需 NPM_TOKEN 可选 CI 集成）；桌面版附带（extraResources + NSIS 注册命令，ELECTRON_RUN_AS_NODE）
- SKILL.md 命令策略：优先全局 `openpptd`，回退 `node <skill>/bin/openpptd.js`
- 更新粒度三件套（SKILL.md/references/CLI）可独立更新亦可整体替换

## 三、skill 流程优化（AI 工作流）★新增
1. **`openpptd doctor`**：环境自检（node 版本/serve 端口/字体库状态/registry 回源可达/示例可用），结构化报告；SKILL.md 引导首次使用与排障先跑
2. **`openpptd check <dir> [--page n]`**：结构自查产品化（必填字段/坐标/主题 token/字体注册名/溢出），页级 lint + 整体校验；**export 自动附带校验并报告**（取代手工跑 tests/package-integrity.mjs，解决该文件不在打包白名单的矛盾）
3. **`openpptd init <dir> [--theme <key>]` / `openpptd new <示例名>`**：标准骨架模板 + 10 套主题预设；复制示例为起点
4. **生成循环强化**：SKILL.md 明确每轮生成/修改前重读 manifest + 相关页面（防覆盖用户边看边改）
5. **`serve --detach` + `serve stop`**：PID 文件管理，改善 Agent 后台预览启停体验

## 四、本地资源目录
```
~/.open-pptd/
├── fonts/            # 字体库（面板/CLI 下载落点；CLI 与桌面版共享）
├── cache/            # 项目缓存（替代 Cache API，按 manifest 哈希，上限保留）
├── drafts/           # 自动保存草稿
├── recents.json      # 最近项目（真实路径，上限 8）
├── settings.json     # 端口、更新源、字体库路径、窗口状态等
└── examples/         # 示例项目（可选下载）
```
资源管理层 lib/resource-dir.js（定位/初始化/迁移旧资产），浏览器侧适配层（线上走 Cache API/IDB）；registry.json 保留仓库内供线上；字体字节一次性迁移脚本

## 五、字体管理面板
字体管理对话框新增「内置字体库」区段（全表/状态/大小/单下/全下/进度/删除）；registry 可线上拉取（URL 可配、失败回退内置）；下载逻辑与 CLI fonts download 共用同一实现（url/mirrors 回源链）

## 六、架构与 skill/Agent 衔接
桌面版=给人用的 GUI、Agent=生产方，衔接点=「文件夹即项目」文件契约；**Agent 不调用桌面端、不借助桌面端导出**（CLI export 无浏览器依赖）；桥接=argv 直开/拖放/文件菜单 + 外部改文件实时刷新；未来特性（不进本次）：编辑器内嵌 Agent 分栏（agent-integration-design.md 草案）

## 七、资源保存逻辑优化（纯前端模型层，双端受益）
1. 撤销栈瘦身：快照剥离 dataURL 图片为轻量引用（字节归 imageMap 单副本），磁盘格式不变
2. 保存直写字节：writeFiles 与 /api/save 增 Uint8Array 分支，去 base64 重编码；同字节多元素统一重写 src
3. 保存流程：页面级 hash dirty 跟踪 + 防抖 + beforeunload 提示 + 自动保存到 drafts
4. 打开优化：懒读并行化、imageMap 孤儿键清理
5. 增强项：插入图片降采样压缩（开关）、zip deflate（CompressionStream）、缓存上限

## 八、Electron 桌面壳
desktop/ 子工程（仅 electron + electron-builder + electron-updater，不污染主仓库零依赖）；主进程内嵌复用 lib/editor-server.js + 动态挂载 /api/project/mount {path}（仅 127.0.0.1）；原生对话框/argv/拖放 → 路径 → 挂载；单实例锁；关闭未保存确认；固定端口 55173（占用递增并持久化）；前端 io 层新增路径模式（URL 模式扩展），句柄模式保留给线上；附带 CLI（extraResources → resources/cli/，NSIS 注册 openpptd 命令 + PATH）；产物：安装器 exe（主）+ portable exe（备）；版本号同步主 package.json

## 九、线上 GitHub Pages 适配
保持完整编辑器（画廊 + 编辑 + zip 降级 + Cache API），相对路径已兼容子路径零改动；验证无 /api 端点降级路径（zip 保存、dirty 语义）不回归

## 十、历史遗留清理与代码合并重构
A 类：双 PPTX writer 核对合并（lib/pptd-export.js vs editor/writer/，writer 纯逻辑化单套双端复用）；base64 编解码收口单一 util（images/handle-io/writer-util/saver）；persistDataUrlImages 与 mediaFilesOfDeck 参数化合并；字体拉取双套共享回源链；能力探测统一 capabilities 模块（gallery detectMode + io.js）
B 类：lib/gallery.js 改名防混淆；font-manager.js 注释错引 pptd-format.md → pptd.md；SKILL.md 引 tests/package-integrity.mjs 矛盾（§三.2 解决）；open-pptd-v2 残留清理
C 类：#edit?deck= 遗留 hash 评估后清理；pptd-io.js 宽容解析 el.extra 明确不回写策略
D 类：parseFontResources 移入 core/font.js；docs 草案标注状态（草案/废弃/现行）、弃用方案清理
E 类：package.json name/description 更新；README 重组；release-workflow.md 同步
原则：A 类放最前、全量测试守门；不为重构而重构
