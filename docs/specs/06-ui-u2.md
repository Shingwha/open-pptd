# Spec A6 · ui-u2：UI 信息架构刀——顶栏 / 右键菜单 / 缩略条 / 深浅色（W4）

> agent 代号 A6，分支 `feat/ui-u2`。深读：`docs/specs/ref/editor-design-reference.html`（样机 §02、右键菜单三态 §03）+ `docs/specs/ref/integration-plan.md` §6.6/§6.7/§6.11、§7.6 U2-1~5。
> 前置阅读：`docs/specs/00-overview.md`。**前置：W3（U1）已合并**——令牌与原语层就绪，本刀是纯信息架构与视觉收口。
> **红线：`packages/` 零 diff**。

## 目标

画布常驻浮层 4→0、顶栏 5 平铺→3 入口、动作进右键、缩放进状态条、深浅色三态可切。`chrome` 三档可用。

## 工单（建议 commit 顺序）

### T1 信息架构 B2（U2-1，布局对齐设计稿 §02 样机）

- 单行顶栏：**插入 ▾ / 设计 ▾ / 放映** 三个入口 + 撤销/重做 + 中间文件名 + 右侧「适配 ▾」「全屏」。字体/配色收进「设计」下拉二级；添加元素收进「插入」下拉。
- 画布零常驻浮层：`.add-menu`（删，并入插入下拉）、`.fab-stack`（删，`fab.css` 内容废弃）、`.zoom-ctl`（挪到底部状态条右侧）、`.quickbar`（收敛为 ≤4 项 + 「更多 ⋮」，其余动作进右键）。
- 底部状态条：缩略条 + 页数统计（等宽数字）+ 缩放控件（−/100%/+）。
- `chrome` 三档落地（接 A2 的 options.chrome）：`"full"` 全量 / `"minimal"`（插入+撤销重做+缩放，隐藏品牌与外链——为将来嵌入式宿主准备）/ `"shot"`（零 chrome、无过渡）。`index.html`/`layout.css`/`toolbar.js`/`editor.js` 协同。
- 消灭 `.zoom.css`/`fab.css` 独立文件（并入 primitives/layout）。

### T2 右键上下文菜单（U2-2，三态菜单逐项对齐设计稿 §03）

新文件 `editor/interaction/contextmenu.js`（用 T1 的 Menu 原语）：
- **单选**：复制（Ctrl+D）/ 删除（Del）/ 分隔 / 置顶 / 上移一层 / 下移一层 / 置底 / 分隔 / 水平翻转 / 垂直翻转 / 分隔 / 对齐到选区（多选解锁）/ 组合（多选解锁）。
- **多选**：对齐到选区 ▸ / 水平分布 / 垂直分布 / 分隔 / 组合 / 取消组合 / 分隔 / 复制（N 个）/ 删除（N 个）。
- **空白处（页面级）**：全选 / 粘贴 / 新建页面 / 页面背景… / 分隔 / 适配画布。
- 快调条各 `types/*.js` 的 `quickbar()` 收敛为 ≤4 项 + ⋮（⋮ 展开菜单复用 Menu 原语）。

### T3 属性面板分区折叠 + 按类型过滤 + 多选「混合」（U2-3）

- 分区改 `<details>` 折叠式 Section（位置与尺寸 / 对齐 / 层级 / 变换 / 类型专属），**按元素类型只显示相关分区**。
- 多选时：可批量设置的属性可编辑，其余显示「混合」占位（斜体、禁用）——对齐设计稿样机的 mix 态。
- 对齐区随单选/多选切换基准标注（U1 已做二义化，此处只做面板呈现收口）。

### T4 缩略条升级（U2-4）

- 右键菜单（复制页/删除页/新建页/背景…）、拖动排序（拖拽手柄 + 落点指示，**排序可撤销**）、页面多选（Shift/Ctrl + 点击，批量删除/复制）。
- 当前页 `outline: 1px solid var(--sel-ring)`；多选页 `--sel-bg` 底色——对齐设计稿 `.th` 样式。

### T5 深浅色三态 + 配色收口（U2-5）

- 三态切换 UI（浅 / 深 / 跟随系统）：位置放「设计」下拉二级或状态条右侧小控件（二选一，报告里说明理由）；跟随系统监听 `prefers-color-scheme` 并响应变化；选择持久化 `localStorage`（独立 serve 场景）。
- 实现：`editor/theme.js` 扩展 `setThemeMode("light"|"dark"|"auto")` → 驱动 `data-pptd-theme`；与 A2 的 `applyThemeTokens` 共存（注入令牌优先于内置板）。
- 配色预设弹层等既有功能在「设计」下的可达性验收（功能不减，只挪入口）。

## 验收（完成前自测）

1. `node tests/run-all.mjs` 全绿；`git diff main -- packages/` 为空。
2. `chrome` 三档各截一套图（`?shot=1` + 临时 query 参数或注入 options），Read 目检：full 有三入口顶栏+状态条；minimal 只剩插入+撤销重做+缩放；shot 零 chrome。
3. 浅/深/跟随系统三态截图；系统主题模拟切换（DevTools 或 CDP）响应正确。
4. 右键菜单三态逐项与设计稿 §03 对照打勾；快调条 ≤4 项 + ⋮。
5. 缩略条：拖排序后 Ctrl+Z 可撤销；页面多选批量删除/复制正常；右键菜单项齐全。
6. 画布区域点击/拖动的命中测试不再把已删浮层算进去（`stage.js:33` 排除清单同步清理）；画廊共用令牌复验。
7. 手动用例报告逐条打勾（同 A5 风格）。
