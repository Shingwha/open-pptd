深浅色：两层主题

组件不知道 light/dark，只有令牌知道

第一层：自带默认板

独立 serve / GitHub Pages 下自足可看，不依赖宿主。补 prefers-color-scheme 与「浅 / 深 / 跟随系统」三态。

07

两刀与回归保障

U1 地基 → U2 信息架构与视觉

U1 · 地基（选择模型 + 令牌 + 原语）

  1. 选择模型改 Set<string> + 框选 + 加选 + Ctrl+A + 分层 Esc
  2. 键位重映射（Shift→多选、Alt→微调/等比/复制拖动）
  3. 对齐语义二义化 + 分布 + 组合
  4. 令牌重建（11 阶中性色、交互态、3 圆角、2 阴影、3 时长）+ 修 7 处硬编码
  5. 原语层 + CSS 18→8
  6. 选中态改 1px 实线环 + 4 角点（消灭 36 处软辉光）

出口：ui-shots.mjs 与基线一致 · run-all.mjs 全绿 · packages/ 零改动

U2 · 信息架构与视觉

  1. 单行顶栏 + 画布零浮层 + 状态条收纳缩放 + chrome 三档
  2. 右键上下文菜单 + 快调条收敛为 4 项 + ⋮
  3. 属性面板分区折叠 + 按类型过滤 + 多选「混合」
  4. 缩略条：右键菜单 · 拖动排序 · 页面多选
  5. 深浅色切换 UI + 配色重做

出口：浅深两套截图 · 三档 chrome 复核 · 画廊共用令牌同步复验
