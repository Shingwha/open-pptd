## 目标

操作方式 PowerPoint 化的地基：多选/框选/加选成立、令牌体系统一、组件原语层建立、CSS 18→8。核心编辑能力一项不减。

## 工单（建议 commit 顺序；T1–T3 行为，T4–T6 视觉，T4 必须先于 T5/T6）

### T1 选择模型改集合（U1-1）

- `state.js`：`selection: Set<string>` 取代 `selectedId` 标量；**`selectedId` 保留为 getter 兼容**（单选时返回唯一 id，多选返回最后选中或 null——所有旧调用点零改动通过）。
- 新交互：框选 marquee（画布空白拖动）、`Shift+点击` 加选、`Ctrl/Cmd+点击` 切换选中、`Ctrl+A` 全选当前页、`Esc` 分层退出（先退框选/多选 → 再取消选中）、`Ctrl+拖动` 复制。
- 选择框渲染：单选 = 1px 实线环 + **4 角控制点**（方形，见设计稿 `.h` 样式）+ 旋转柄；多选 = 各成员 1px 细边框 + 一个虚线包围盒 + 四角手柄；框选 = 虚线 marquee。**消灭 8 圆点手柄**。
- 涉及：`app/state.js`、`app/api.js`、`interaction/canvas.js`、`interaction/stage.js`、`app/view/view.js`、`app/toolbar.js`、`app/keyboard.js`、`interaction/properties.js` 的消费点（30+ 处，逐个核对）。

### T2 键位重映射（U1-2，全表见设计稿 §04）

| 键 | 改为 |
|---|---|
| `Shift`+点击/拖动 | **加选**（不再是大步微调/等比） |
| `Alt` | 微调 10px / 等比缩放 / 拖动复制（承接 Shift 让出的语义） |
| `Ctrl/Cmd`+点击 | 切换选中 |
| `Ctrl+A` / `Ctrl+G` / `Ctrl+Shift+G` | 全选 / 组合 / 取消组合 |
| `Esc` | 分层退出 |
| 方向键 | 1px / `Alt` 10px / `Shift` 网格吸附 |
| `Ctrl+D` / `Ctrl+Z/Y/S` | 保留 |

顶栏「帮助/快捷键」处给完整键位表（U2 若做帮助入口，先放进属性面板顶部或 tooltips，U2 再收口）。

### T3 对齐语义二义化 + 分布 + 组合（U1-3）

- 单选 → 对齐**页面**；多选 → 对齐**选区包围盒**；属性面板标题随数量变化（「对齐（页面）/「对齐（选区）」），画布上多选时画选区虚线框区分基准。
- 新增水平/垂直**分布**（多选 ≥3 个可用）。
- 新增 `editor/types/group.js`：`group` 元素类型（组合/取消组合，`Ctrl+G`/`Ctrl+Shift+G`），注册进 `types/index.js`；组合往返幂等；组内元素可进组编辑（双击）或整体变换——以实现简单、行为可预期为准，写入 commit message 说明取舍。
- 渲染：`packages/renderer` **不改**——group 若需要渲染支持，走 editor 侧展开渲染（组=子元素集合），确需动 packages 时停下来在报告里说明（默认不许）。

### T4 令牌体系重建（U1-4，值从设计稿 `:root` 与 `[data-theme="dark"]` 逐条照抄）

`editor/styles/tokens.css` 重写为设计稿令牌板：11 阶中性色 `--n-0…--n-900`（浅深两套完整值，设计稿已给）+ 语义别名（`--bg/--panel/--line/--line-strong/--ink/--sub/--faint/--hover/--active/--disabled/--sel-bg/--sel-ring`）+ 强调/语义色（--accent 系、--danger/--success/--warning 及各自 -soft）+ `--r-1/2/3` + `--sh-pop/--sh-modal` + `--t-fast/med/slow` + `--ease` + `--h-sm/--h/--h-lg` + `--f-xs…--f-xl` + `--font/--mono`。保留 A2 已加的 `--mask`、`--chip-border` 并给 dark 值。**旧令牌名**（--radius/--radius-sm/--radius-lg/--text-*/--z-* 等）以别名形式保留指向新令牌（`--radius: var(--r-2)` 之类），未迁移组件不破；组件侧由 T5 逐步切到新名。深浅色：`:root` 放 light，`[data-pptd-theme="dark"]`（沿用 A2 的属性选择器）放 dark，**组件永远不知道 light/dark**。

全仓 CSS 硬编码清零：`#hex`/`rgba()` 字面量 = 0（`present.css` 的放映中性面除外）；圆角取值 ≤3 种；transition 形态 ≤4 种；裸 `z-index` = 0（并入 5 档 z 令牌）。

### T5 组件原语层 + CSS 18→8（U1-5）

- 新目录 `editor/components/`，原语函数（原生 DOM，不引 React）：`Button`（3 尺寸×4 变体：默认/主/幽灵/危险 + icon）、`Field`（沿用 `interaction/fields.js` 的 5 种 kind，只换令牌——该文件架构保留）、`Section`（可折叠分组）、`Panel`、`Dialog`（沿用 `dialogs/base.js` 骨架）、`Menu`（ submenu/快捷键提示/图标位）、`Popover`（4 锚点方向）、`Tooltip`（400ms 延迟）、`DataGrid`（键盘导航+范围选择）、`Toolbar`（分组+溢出折叠）。样式集中 `editor/styles/primitives.css`。
- CSS 收敛为 8 文件（映射见 §6.10）：`tokens` / `primitives` / `layout`（absorb topbar+thumbbar）/ `canvas`（absorb quickbar）/ `inspector` / `panels`（gallery+excel-grid）/ `present`（+shot）/ `responsive`。`index.html` link 列表同步；**去掉加载顺序依赖**（打乱 link 顺序仍正确——用选择器特异性而非顺序覆盖）。
- 类名目标 ~110 个：`.btn/.icon-btn/.status-btn/.thumb-add` 等重复定义收进 Button 原语；孤儿类清理。

### T6 选中态视觉（U1-6）

`outline: 1px solid var(--sel-ring)` + 4 角点；`grep '0 0 0 3px' editor/styles/*.css` = 0（36 处软辉光全灭）；单选/多选在浅深两色下都可辨（对照设计稿 §02 样机三种选择态）。
